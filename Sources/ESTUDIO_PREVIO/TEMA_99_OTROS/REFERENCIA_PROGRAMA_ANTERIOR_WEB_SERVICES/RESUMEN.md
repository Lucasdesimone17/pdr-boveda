---

## Por qué este tema está vacío

`TEORICO/06_WEB_SERVICES/` está **vacía** — no hay ningún PDF, guía ni diapositiva de Aulas sobre Web Services todavía (auditoría más reciente: `ROADMAP.md`, 12/08/2026). Ni SOAP ni WSDL aparecen en ningún material oficial descargado hasta la fecha.

La versión anterior de este archivo tenía contenido de **Sockets** (modelo TCP/IP, clase `Socket`, TCP vs UDP, `TcpClient`/`TcpListener`) sacado de `0.RESUMEN-STUDOCU.pdf`. Ese contenido **no es específico de Web Services** — es la base de comunicación en red que ya está cubierta correctamente, con fuente oficial (`5-Sockets.pdf` + guías), en:

👉 **`ESTUDIO/TEMA_02_SOCKETS/`**

Por eso se sacó de acá: dejarlo duplicado bajo el nombre "Web Services" generaba la falsa impresión de que el tema estaba cubierto, cuando en realidad SOAP/WSDL/UDDI —lo que el programa oficial pide específicamente— sigue sin ningún material.

---

## Qué falta para desbloquear este tema

1. Que el docente suba a Aulas material específico de Web Services (lo más probable: SOAP, WSDL, posiblemente UDDI).
2. Una vez descargado, colocarlo en `TEORICO/06_WEB_SERVICES/`.
3. Recién ahí se puede reescribir este RESUMEN.md (y CHEATSHEET.md, PREGUNTAS.md, HTML) siguiendo el mismo procedimiento que Temas 3, 4 y 5: fuente oficial primero, StuDocu solo como complemento puntual y marcado como 🟠 no oficial.

No se completa con contenido inferido porque se conserva únicamente como registro del mapa anterior. El temario vigente ya define Sockets como Tema 2 y APIs REST como Tema 6.
