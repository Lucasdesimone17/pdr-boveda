Ejercicio 3
Una farmacia lo contrata para diseñar un sistema para administrar el local.
Debido a la creciente demanda el sistema debe ser capaz de soportar varios usuarios
simultáneamente para evitar perder posibles clientes.
Se espera del sistema que pueda operar de la siguiente forma:
Repartidores
Los repartidos del local tienen una aplicación de la farmacia que envía su ubicación en tiempo real
al servidor
Totem de Autogestión del local:
Cada una está equipada para realizar el pedido desde la misma y recibir el pedido de parte de un
empleado.
Servidor:
Se debe encargar de recibir las peticiones, procesarlas y generar una respuesta de ser necesario
Dispositivos móviles:
Página web para que los clientes puedan ver el catálogo desde su celular y realizar pedidos
Con esto en mente se pide diseñar un concepto de sistema que realice lo descrito, en concreto
definir qué mecanismo de comunicación se utilizará en cada punto.
Adicionalmente diagrame los componentes que considere necesario (Móviles, Totems,
Repartidores, Servidor [puede dividirse en varios componentes]).
Para esto se requiere utilizar 3 de las siguientes tecnologías sockets/tcpListener/tcpClient, MOM,
gRPC, API REST.
Quedando bajo su criterio cómo utilizarlos, justifique su elección y que información viaja (ej
protocolo básico para sockets, protobuf en gRPC, etc)
